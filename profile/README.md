# mobi-rud

Мобільні та вебінструменти для торгових команд: клієнти, маршрути, замовлення, взаєморозрахунки й обмін даними.

| Проєкт | Призначення |
|---|---|
| [torg_server](https://github.com/mobi-rud/torg_server) | Серверне API та інтеграції |
| [torg_web](https://github.com/mobi-rud/torg_web) | Вебзастосунок |
| [torg2](https://github.com/mobi-rud/torg2) | Мобільний застосунок із роботою офлайн |
| [onec-docs](https://github.com/mobi-rud/onec-docs) | Документація та модулі обміну 1С |
| [docs](https://github.com/mobi-rud/docs) | Загальна документація організації |

Приватні репозиторії доступні учасникам із відповідними правами.
